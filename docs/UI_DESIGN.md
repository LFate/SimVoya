# SimVoya · UI 设计

## 产品与交互

macOS 原生单窗口工具，中文名称「SimVoya」，副标题「把文件送进模拟器」。任务只有三步：选择正在运行的设备 → 拖入文件 → 查看逐项结果。主窗口直接展示工作区，无欢迎页、登录、设置页或启动向导。

默认窗口 860 × 620 pt，最小 720 × 520 pt。使用原生标题栏和 traffic lights；工具栏右侧两个文字按钮「打开模拟器」「刷新」，刷新快捷键 ⌘R。标题栏下面左右两栏，左栏固定 228 pt，右栏随窗口扩展。整页跟随系统浅色/深色模式。

## 页面效果

```text
┌ ● ● ●   SimVoya                         打开模拟器   刷新 ↻ ┐
│ 正在运行 · 2       │ 把文件送进模拟器                         │
│                    │ 目标设备  iPhone 17 Pro · iOS 27.1       │
│ ▣ iPhone 17 Pro    │                                         │
│   iOS 27.1    运行中│ ┌─────────────────────────────────────┐ │
│                    │ │                 ↓                   │ │
│ ▣ iPad Pro         │ │        拖入图片、视频或文件          │ │
│   iOS 27.1    运行中│ │         或「选择文件…」              │ │
│                    │ │                                     │ │
│                    │ └─────────────────────────────────────┘ │
│                    │ 图片和视频 → 照片                       │
│                    │ 其他文件 → 文件 App / SimVoya            │
│                    │                                         │
│                    │ 最近导入                         清空    │
│                    │ ✓ screenshot.png         已导入「照片」  │
```

普通文件目标为「文件 App → 我的 iPhone → SimVoya」，架构已确认可通过 DocumentsApp 的本地 File Provider Storage 导入。此路径属于兼容性方案，必须在真实文件 App 验证后才显示「已导入『文件』」；若只能确认复制完成，结果写「已复制到文件存储」，并提示「如未出现，请重新打开文件 App」。路径发现失败时显示错误，禁止猜测容器路径。

## 视觉系统

- 字体使用系统 SF / 苹方。页面主标题 24 pt semibold，设备名 13 pt medium，正文 13 pt，辅助文字 12 pt。文件名支持中间省略，完整文件名和结果可通过 tooltip 查看。
- 4 pt 基础栅格；内容外边距 28 pt，组件间距 16/24 pt。左栏内边距 12 pt，设备卡片内边距 12 pt，最小高度 68 pt，圆角 10 pt。
- 背景使用系统 windowBackgroundColor，左栏使用 underPageBackgroundColor 或原生 sidebar 材质。主要文字 labelColor，次要文字 secondaryLabelColor。分割线系统 separatorColor，杜绝纯灰写死导致深色不可读。
- 唯一强调色为靛蓝：浅色 #4F46E5，深色 #A5B4FC。浅色白底下靛蓝文本约 6.3:1，对应深色使用系统深背景。选中设备浅色填充 #EEF2FF，深色使用 accentColor 约 18% 混合；选中状态同时有 leading 3 pt 色条或勾选标记。
- 成功图标使用系统 green，失败图标使用系统 red；均配文字结果，不能只依赖颜色。
- 拖拽区高 210 pt，圆角 18 pt，1 pt 虚线边框，底色采用强调色 3% 混合。中央图标 tray.and.arrow.down 32 pt；主文案 17 pt semibold；按钮为原生 bordered「选择文件…」。鼠标悬停可无动画；有效拖入高亮实线 2 pt、底色 8%，提示「松开以导入到 iPhone 17 Pro」。

## 设备选择

只列 state=Booted 的可用设备，显示名称、运行时、绿色点与「运行中」。默认选中第一台，后续刷新保持设备 UUID 选择。每 3 秒轻量更新，手动刷新提供即时反馈。设备多于可见高度时左栏滚动，不扩张窗口。

没有运行设备：左栏「暂无运行中的设备」，主区居中设备图标、标题「先启动一台模拟器」、正文「启动后会自动出现在这里。」及主按钮「打开模拟器」。不显示看似能接受导入的拖拽框。读取失败与真正无设备区分：标题「无法读取模拟器」，显示可理解的原因与「重试」；原始命令错误可在可展开的详情中查看。

选中设备关闭后立即取消选择，不静默改投其他设备。提示「这台模拟器已关闭，请选择运行中的设备」。若导入进行中，则保持原目标快照，逐项报告失败，绝不切换目标。

## 导入与反馈

支持 Finder 多文件拖入以及 ⌘O 选择文件；两者完全相同的执行路径。拖拽区上方放原生 segmented picker「自动 / 照片 / 文件」，默认「自动」按媒体/普通文件分流，区域下方常驻显示目标说明。照片模式说明「图片和视频将导入照片」，文件模式说明「所有内容将导入文件 App → SimVoya」。选择记忆仅限当前会话。导入开始时冻结本批目标设备，设备列表可浏览但批次目的地不变化。

导入中：拖拽区标题「正在导入 2 / 5」，次级文字「到 iPhone 17 Pro」，使用 ProgressView。禁止重复提交，保留可见状态；不提供无法正确终止底层命令的伪取消。

底部「最近导入」以紧凑列表显示文件图标、文件名、状态和目的地。进行中为 spinner，成功为 checkmark.circle.fill，失败为 exclamationmark.circle.fill + 原因摘要。批次完成显示「已导入 4 项，1 项失败」，部分失败不显示全部成功。列表保留本次会话最近 50 项，支持滚动；「清空」只清空历史，不删除源文件或模拟器文件。失败保留可读详情与「重试」入口（实现若不提供重试按钮，则通过重新拖入重试，并明确文字）。

文件夹在「文件」模式保留目录结构导入；「自动」模式也将文件夹作为文件目标处理。「照片」模式拒绝文件夹，并提示「文件夹请选择『文件』模式」。对不支持的媒体格式若 addmedia 失败，显示真实错误，不把未经确认的结果称为成功。同名普通文件应保留两份并自动附加编号，避免覆盖；最终目标名称在结果详情中可查。

## 无障碍与验收

原生 SwiftUI 控件优先，完整支持 Tab、Space、Return。设备行为使用 selectable List，VoiceOver 读出设备名称、运行时、选中状态。图标按钮附 accessibilityLabel 与 tooltip。主拖拽区必须有「选择文件…」作为键盘替代。常规文字对比度至少 4.5:1，状态通过图标和文字双重表达；遵循 Reduce Motion，无持续装饰动画。窗口缩放时右栏优先扩展，长名称截断但不挤走结果。

验收应覆盖 0/1/多台设备、设备运行状态改变、单张图片、多文件、普通 PDF、部分失败、中文和空格文件名、深色模式、键盘选择。截图中不能出现写死的假设备、假成功记录。

## App icon

资源见 `Assets/AppIcon.svg`：1024 × 1024，靛蓝圆角底板、白色手机轮廓和向下箭头。轮廓代表 Simulator，落入设备的箭头代表导入；手机内底部一条短横暗示接收托盘。无文字、无小尺寸细节。开发阶段从 SVG 等比例栅格化到 16/32/64/128/256/512/1024 px 并生成 macOS .icns；不得简单把 SVG 后缀改为 PNG。
