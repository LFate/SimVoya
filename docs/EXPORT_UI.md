# SimVoya 导出页面设计

## 目标与视觉基础

在现有单窗口中增加「导入 / 导出」两种工作模式。沿用左侧运行设备列表、系统字体、靛蓝强调色和浅深色模式。导出任务为：选择模拟器 → 找到文件 → 拖到 Finder。保留「导出所选…」按钮作为键盘替代与拖拽失败时的正常入口。

默认窗口建议 1040 × 720 pt，最小 900 × 620 pt；左设备栏维持 228 pt。右内容外边距 24 pt，区块间距 16 pt；四列列表随宽度扩展。标题 24 pt semibold，正文及文件名 13 pt，辅助文字 11–12 pt。使用系统 label / secondaryLabel / separator / windowBackground 语义色；正常文字对比度至少 4.5:1，状态同时以图标和文字表达。

模式切换使用原生 segmented picker，宽 180 pt，置于右工作区顶部，读作「工作模式」。初始保持导入，避免改变旧用户启动习惯。导出页标题「从模拟器取出文件」，副标题为选定设备名和运行时。

## 文件来源与覆盖范围

来源是原生菜单，顶层四类。设备信息已有 dataPath，listapps 可提供 App 显示名称、DataContainer 和 GroupContainers；界面使用已发现的实际映射，不拼接猜测路径：

| 来源 | 初始内容 | 下钻方式 |
| --- | --- | --- |
| 文件 App 本地文件（默认） | LocalStorage 对应的本地存储根，不局限于 SimVoya 子目录 | 双击文件夹逐层进入 |
| 应用数据 | 可发现的 App 列表，名称为主，bundle ID 作辅助；选中 App 后显示其数据容器 | 先显示 Documents、Library、tmp 等真实目录，Documents 可作为快捷入口 |
| 共享容器 | 可发现的 App Group 列表，组标识及所属 App 作为辅助信息 | 选择组后逐层浏览；无法映射的组不能假定所属 App |
| 设备数据 | 所选模拟器可访问的 data 根 | 逐层浏览，以覆盖未映射到前述来源的可读内容；UI 标注「高级位置」 |

应用列表不能只显示启用了文件共享的 App，否则会漏掉 App 内生成的压缩包；即使 Documents 为空，也应能访问该 App 的其他可读数据目录。设备数据不等于整台 Mac 的文件选择器，导航不得跳出当前模拟器 data 根。

首次选择应用数据/共享容器时可在同一列表展示来源条目，双击条目进入容器；无需再增加一层侧栏。来源条目用文件夹/应用图标、名称、bundle ID/组 ID；显示加载失败的 App 为不可用条目并附原因，不静默当作空目录。App 条目若很多，搜索框在此层搜索名称和 bundle ID。

所有来源均采用按层读取，不能为了打开页面就递归扫描整台设备；“所有可获取内容”通过可导航的真实目录覆盖，不承诺访问系统保护区、云端尚未下载内容或虚拟提供器后端。

## 列表、导航与信息

优先采用原生 NSTableView（便于原生拖出 file promise）；表格高度占满剩余工作区，行高 32 pt，列标题 12 pt semibold，交替行底色或细分隔线使用系统样式。名称列伸缩，最小 220 pt；类型 90 pt；大小 76 pt 右对齐；修改时间 130 pt。默认文件夹在前、名称自然排序；支持点列标题排序，至少名称/大小/修改时间。

- 文件名中间截断，tooltip 显示完整名称。使用系统文件图标；压缩包可显示通用 archivebox 图标，不检测或猜测是否加密。
- 文件夹大小显示「—」，避免主线程递归计算；文件显示格式化字节数，详情可显示精确 bytes。未知值显示「未知」，不能显示成 0。
- 右键/信息按钮「查看信息」展示完整名称、类型、大小、修改时间、来源和相对路径，以及是否可读。绝对路径可放在可复制的详情内，不作为列表主信息。
- 上一级按钮与可点击面包屑导航。根部上一级禁用。双击文件夹/Return 进入；双击普通文件不解压、不自动启动模拟器程序，可显示信息或无额外动作。
- ⌘ / Shift 多选；⌘A 选择当前列表可选条目。下钻、换来源和换设备均清空选择，防止把不可见旧选择导出。
- 搜索仅过滤当前文件夹，placeholder 必须写「搜索当前文件夹」，不暗示全盘递归搜索。空搜索结果写「没有匹配的文件」，保留清除搜索入口。
- 显示隐藏文件 checkbox 放在列表工具条或更多菜单中，默认关闭；设备数据来源须提供该项以便浏览点开头条目。默认隐藏时显示「已隐藏点开头文件」提示，避免宣称无遗漏。

## 直接拖到 Mac

鼠标从选中行开始拖拽时，整个选择成为导出批次；从未选中行开始拖拽则先只选择该行。拖拽预览显示文件图标、名称和多选数量；操作固定为复制，不提供“移动”语义。用户松开到 Finder 文件夹、桌面或支持文件承诺的目标后，后台创建实际导出内容；不能仅把模拟器内部文件 URL 交给 Finder 后就声称导出完成。

文件和整个文件夹均支持 file promise；加密压缩包按原始字节复制，不解压、不询问密码。接收端取消拖拽时不创建导出成功记录。若接收端不支持 file promise，提供说明「请拖到 Finder，或使用『导出所选…』」。

- 拖出开始后冻结设备、来源、文件 URL 与名称；随后导航/设备变化不能改投其他内容。
- 拖拽准备不能同步扫描或校验大目录，UI 不能卡顿；真实复制在目标确定后进行。
- 批次中包含父目录与其后代时，保留最上层选择，避免重复导出；用户当前常规同层多选不会出现此情况。
- 同名目标保留两份，生成编号名称；不能覆盖现有 Mac 文件。最终名称必须在结果详情可见。
- 源文件不可读、已消失、正在变化、内容校验失败时逐项显示错误；不显示全部成功，也不删除模拟器原文件。

## 导出按钮与结果状态

底部固定操作栏高约 44 pt，左侧「N 项 · 已选 M 项」，右侧主按钮「导出所选…」。无选择、无有效来源或读取中禁用。按钮打开 Mac 目录选择面板，与拖拽共用相同导出服务。按钮快捷键可用 ⇧⌘E；保留 ⌘O 作为原有导入入口，不在导出页意外触发导入。

进行中在底部显示 spinner / ProgressView 及「正在导出 2 / 5 · backup.7z」，具体字节进度只有实现确知时才展示，不伪造百分比。允许继续浏览，但同一批次禁止重复提交。未实现完整取消时不显示伪取消按钮。

底部结果区默认仅显示最近批次摘要，占约 52–100 pt，可展开查看逐项结果并滚动；不挤压文件列表。成功项「已导出」+ 实际目标文件名 +「在 Finder 中显示」；失败项「导出失败」+可展开原因。「清空记录」只清界面历史。操作记录区别「导入」与「导出」，避免导出结果写进“最近导入”。

加载目录：列表区域显示 spinner 与「正在读取文件…」，保留来源/面包屑；不显示旧目录冒充新数据。空目录显示「这个文件夹为空」。权限不足显示「无法读取此文件夹」及可展开原因和“返回上一级”；某些条目不可读时仍显示该条目和「无法读取」状态，不阻断其他条目。

云端占位/未下载条目在能可靠识别时显示「尚未下载」并禁用导出；不能可靠识别时只按实际可读性/复制结果判断，不把零字节等价于占位文件（合法空文件允许导出）。符号链接行显示类型「符号链接」，默认不可导出/不可跟随，并说明原因。

## 设备变化、刷新与无障碍

沿用无设备和设备查询失败的现有空态。设备关闭后显示「这台模拟器已关闭，请选择运行中的设备」，清除浏览列表与选择；正在导出的批次保持冻结源，按实际读取结果报告完成或失败。设备每 3 秒刷新不应把文件列表选择重置；文件列表使用用户主动刷新（⌘R 在导出页同时刷新当前来源/目录），避免写入中的目录持续跳动。

支持系统深色模式、Reduce Motion、Tab/方向键/Space/Return 操作。所有图标按钮提供中文 accessibilityLabel 和 tooltip。VoiceOver 逐行读出名称、类型、大小、修改时间、可访问状态与选择状态。导出按钮提供与拖拽等价的无鼠标操作。选中行用系统 selection 样式，选中状态的辅助文字采用系统强调后的可读颜色，避免绿字叠蓝底导致低对比。

## 交接验收

1. 可列出 Files 本地根，以及某个 App 的 Documents 和更深目录；设备 data 根允许导航其他可读目录。
2. 文件元信息真实，未知值不伪装成空文件；大目录按层加载不冻结 UI。
3. 多选普通文件、文件夹与加密压缩包拖到 Finder，Mac 上收到实际内容；取消拖拽无假成功。
4. 导出前后内容校验一致，原文件保留，同名目标不会被覆盖；压缩包不要求密码。
5. 导出按钮与拖拽结果一致，失败能看原因；不可读、symlink、空目录、搜索无结果的状态分别可识别。
6. 更换设备/来源时选择不串用；刷新不产生旧请求覆盖新目录。深色与键盘路径可用。
