# SimVoya 1.1.0 导出验证

日期：2026-11-04。环境：Apple Silicon Mac、macOS 27.2、Xcode 27.2、iPhone 18 Pro Max / iOS 27.2 Simulator。

## 构建与自动测试

- release App 版本 1.1.0 / build 2，codesign --verify 通过。
- 最终 swift test：9 项通过，1 项显式 live 测试默认跳过，0 失败。
- 单独设置 SIMVOYA_LIVE_EXPORT_DEVICE 启用 live 测试：1 项通过。
- 自动测试涵盖来源解析/共享根去重、隐藏文件与元信息、路径越界/符号链接拒绝、目录结构/空文件/空目录、并发重名导出、目标冲突保护。
- 原生 NSFilePromiseProviderDelegate 集成测试实际调用 fulfillment：普通文件与文件夹都写入 Finder 指定的精确目标名称，completion 一次，已有目标不覆盖。此测试不等同于真正鼠标拖至 Finder。

## GUI 已验证

- 从导入切换至导出，真实设备和本地目录正确显示。
- 双击进入本地目录与两层下级目录，能看到测试文件的真实名称、类型、大小和修改时间。
- 应用数据来源实际显示 40 个系统/用户 App；无可发现容器的条目保留并标明不可导出。
- 按 bundle ID 筛选一个已安装 App，逐级进入其数据根、Documents 和日志子目录；文件名称、大小与时间可读取。未复制或发布该 App 的实际日志内容。
- 查看信息面板显示完整路径、精确字节数、创建/修改时间和可读状态。
- Cmd+A 多选测试文件夹、加密 ZIP 和文本，通过「导出所选…」选择 Mac 目录完成导出。
- Mac 实际输出位于 /tmp/SimVoya-Button-Export-20261104，三项源与输出内容再次逐项校验一致，原文件保留；ZIP 加密标志再次检查通过。
- 实际导出页面截图为 docs/screenshots/export-browser.jpg，只包含本项目创建的测试文件。
